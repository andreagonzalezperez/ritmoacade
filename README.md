# RitmoAcade 4.0

PWA estática, local-first y compatible con GitHub Pages.

Incluye:
- Hoy: próxima actividad, tareas, exámenes y objetivo semanal.
- Calendario mensual y actividades semanales recurrentes.
- Asignaturas con profesor, contacto, aula, curso, horario y acciones.
- Estudio con sesiones, temporizador y estadísticas semanales.
- Repertorio con compositor, obra, dificultad, estado, progreso, fecha objetivo, profesor, asignatura, memorización y problemas técnicos.
- Tareas con categoría, prioridad, estado, fecha, horario y mini tareas con progreso automático.
- Exámenes con convocatoria, estado, fecha, nota y cuenta atrás.
- Ensayos con agrupación, instrumento, director, lugar, prioridad y repertorio.
- Eventos.
- Búsqueda global.
- Configuración de listas desplegables y perfil.
- Exportación/importación de copia JSON.
- Funcionamiento offline mediante service worker.

Importante:
- Los datos se guardan localmente en el navegador del dispositivo.
- GitHub Pages sirve los archivos estáticos; no hay servidor ni base de datos.
- No subas información sensible al repositorio.
