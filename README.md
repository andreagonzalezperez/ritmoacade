# RitmoAcade 2.0
Versión móvil/PWA avanzada y autocontenida.

Módulos:
- Hoy
- Horario/calendario
- Estudio + objetivo semanal + temporizador
- Repertorio con progreso
- Tareas y prioridades
- Ensayos, clases y conciertos
- Exámenes
- Estadísticas
- Exportación/importación de datos
- Persistencia local
- Service worker para uso offline una vez cargada

Para instalarla en iPhone necesita publicarse en una URL HTTPS. El paquete está listo para subir a un servicio de hosting estático gratuito.
